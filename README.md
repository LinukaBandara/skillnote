# SkillNote

SkillNote is a learning management platform for Sri Lankan A/L students, built around structured syllabus tracking, courses, lessons, quizzes, mock exams, question banks, study planning, certificates, and discussion workflows.

## Stack
- Next.js / React / TypeScript
- Supabase (Postgres, Auth, Row Level Security)
- Tailwind CSS

## Core areas
- Syllabus and topic mastery tracking
- Course and lesson delivery
- MCQ question bank and timed mock exams
- Weak-topic and study-plan workflows
- Certificates and public verification
- Institute and role management
- Admin content and assessment management

## Local development
npm install
npm run dev

Create .env.local from the project's environment example and provide the required Supabase configuration. Never commit secrets or production credentials.

## Status
SkillNote is an active product build. Content, assessments, and production configuration are still being populated and refined.
